# CodeCourse 界面优化记录 · 2026-09-09

本轮围绕个人使用的轻松学习氛围调整桌面前端，保留现有功能。参考 [Emil Kowalski 的设计工程指南](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md)，重点采用高频操作即时响应、克制动效、清晰状态和键盘可访问性原则。

| Before | After | Why |
| --- | --- | --- |
| 桌面界面偏工具面板，层级和装饰较重 | 柔和靛紫配色、学习岛插画、圆角阅读区域和统一深浅主题 | 提供适合个人学习的轻松视觉氛围 |
| 实际课件使用 `lessons/lesson_01.md`，工具栏路径识别不一致 | 工具栏、侧栏和课程列表统一使用 `isLessonPath` | 恢复完成按钮，让已有进度正常更新 |
| 阅读页重复标题工具栏 | 合并课程操作，突出完成按钮，优化正文行高、留白与代码块 | 减少阅读干扰，让操作更容易找到 |
| 进度只呈现计数和条形 | 以现有完成数据点亮装饰星星，完成确认后短暂反馈 | 增加轻量趣味，不添加任务或收集系统 |
| 课程操作按钮挤占标题空间 | 鼠标悬停或键盘聚焦时显示覆盖操作，触屏保留可见入口 | 改善长标题显示，同时保留操作可达性 |
| 窄窗口保留已移除活动栏的 48px 网格 | 阅读区占满网格，侧栏与助手使用覆盖面板 | 修复窄窗口阅读区域被挤压的问题 |
| 搜索打开和关闭有延时，键盘焦点处理不足 | 即时开关、焦点恢复、Tab 限定、组合输入保护和列表语义 | 让高频搜索更直接，避免中文输入误执行 |
| 深色搜索选中状态对比不足 | 柔和强调底色与可读前景色 | 保持选中项和说明清晰 |
| 高频切换带入场动画 | 移除重复导航动画，完成反馈控制在 280ms，支持减少动态效果 | 兼顾趣味与响应速度 |

## 后续细节修整

| Before | After | Why |
| --- | --- | --- |
| 设置分组标题、说明和平台提示沿用固定颜色 | 统一使用深浅主题文字、背景及分隔线变量 | 修复深色模式下的低对比问题 |
| 设置分组缺少层次，输入框与其他页面尺寸不一致 | 分组卡片、40px 输入框、固定不收缩的标题和操作区，小窗口单列字段 | 改善设置页的阅读顺序和窄窗口使用体验 |

| 菜单悬停说明文字仍沿用白色 | 使用主题次级文字，补充菜单键盘焦点背景 | 避免说明文字在浅色高亮背景上消失 |
| 搜索无结果提示紧贴列表 | 统一提示留白、行高和文字色 | 让空状态清晰易读 |
