# Android 桌面数据包导入修复（2026-10-15）

## 原因与行为

桌面导出的 CodeCourse ZIP 是包含独立项目清单及数据库快照的完整备份。Android 的“导入本地 ZIP”原先统一按单个源码仓库解压，导致多个项目嵌套在一个源码树内，生成的 Markdown 课件也被当成源码打开。

- ZIP 入口现在读取包内格式，自动选择源码导入或完整数据恢复；重命名 ZIP 不影响识别。
- 数据恢复前显示项目数量、项目名称及替换手机数据的确认。取消时不会创建源码项目，也不会修改现有数据。
- 原项目 ID、项目类型及每个项目独立的课件路径保持不变；同名 `lessons/lesson_01.md` 不会跨项目覆盖。Markdown 课件进入课程目录，以现有 Markdown 阅读器显示。
- Android 源码导入服务与桌面本地 ZIP 服务拒绝将 CodeCourse 数据包直接当单个源码仓库解压。
- 新桌面导出不再把 `.tasks` 章节片段、`.previews` 预览 JSON 等内部文件写成课件。Android 仍兼容原始旧数据包，但不将这些临时文件列入课件目录。

## 验证

- 使用用户本次实际桌面导出包，在独立内存 SQLite 和隔离文件系统中运行 Android 完整导入：3 个项目分别恢复，项目类型、每个 Markdown 文件内容及所属项目逐项一致。原 ZIP 和当前桌面用户数据未被修改。
- 新增回归：重命名备份自动识别、普通源码 ZIP 正常导入、损坏备份不降级成源码、服务层防止合并项目、不同项目的同名 Markdown 隔离、生成临时文件过滤。
- 前端 114 个文件、621 项测试通过（含启用实际导出包的本地回归）；后端 389 项测试通过。
- APK 使用原旧版证书签名，并与旧版实际 APK 核对包名、签名及版本号；不要求卸载旧版。

## 使用

安装 `CodeCourse-0.4.9-android-import-fix.apk` 覆盖升级后，重新选择原桌面导出的 ZIP。界面应显示识别到 3 个独立项目；确认后按原项目恢复。恢复会替换手机当前 CodeCourse 数据，请先备份手机上需要保留的新内容。之前错误导入形成的单个源码项目不会被当作课件继续使用。

本次无连接的 Android 真机，实际覆盖安装和 WebView 手工点击待用户设备确认。原生构建、签名、隐私扫描和桌面安装核对结果见本地 `tmp/android-import-fix-verification.json`。
