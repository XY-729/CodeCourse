- 同一完成状态的重复保存不重复累计；取消完成会撤销本次完成证据，重新标记后只保留一份有效证据。

- 已学范围写入总纲、课件章节规划、正文生成和问答上下文。明确困惑和重新讲解的要求优先；已学过不等于已掌握。
