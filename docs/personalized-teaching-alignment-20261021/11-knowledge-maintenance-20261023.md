# 个性化学习：历史补录、范围去重、知识树整理

本次实现对应优化方向 1、2、4，桌面和 Android 共用前端入口，各自使用本地数据库。主题、层叠工作区和拖动缩放行为不变。

## 历史知识补录

在学习档案或正文中的“检查历史知识关联”入口检查文档。旧版清单即使显示已完成，也会进入待升级列表；已完成或已确认理解的文档优先排列。

1. 勾选文档，生成知识清单预览。长文按段扫描，使用当前配置的模型。
2. 预览展示新增或复用的概念、父分类和原文范围，此时不写入知识树。
3. 点击“确认应用预览清单”后，通过身份、作用域、父子关系和引用校验，再事务性保存索引。
4. 可以撤销单次补录；相关知识出现后续修改或新学习记录时，拒绝覆盖，提示手动调整。

清单存于数据库附属记录，不改写历史正文。扫描本身不代表学过或理解；只有已有的明确课程完成记录，才按原完成时间恢复“已学过”。原有反馈和原始证据保留。预览后原文变化时，应用会失败并要求重新预览。

## 学习范围的稳定身份

范围身份由概念、维度、规范范围共同确定，生成上下文包含已有范围编号及同义名称。模型需要复用同义范围的编号和规范名；本地检查编号是否属于对应概念与维度，防止误归类。

“扩容原理”和“扩容机制”等同义范围可由用户明确关联。状态重算时统一为规范范围，原始学习证据不改写。不会根据相似词自动合并不同知识范围。

## 知识树整理

学习档案的知识树节点旁新增“整理”：

- 移动分类：调整父分类或作为根分类，拒绝循环和不合法的私有父节点。
- 重命名：保留原名称作为别名。
- 合并重复概念：保留目标节点，转移来源、反馈、别名和学习证据；旧编号保留重定向。
- 拆分原文范围：勾选具体讲解段落，新建同级概念，只迁移所选范围及其对应反馈，不复制全部熟悉度。重新索引时保留拆分归属。
- 关联同义范围：选择维度、规范范围和同义名称。

“修改记录与撤销”可查看最近的修改并撤销。共享概念的整理会影响使用该概念的其他项目。

## 删除项目

删除与该项目关联的课程索引、提问记录、学习证据、补录预览、纠正记录及专属概念。其他项目仍在使用的共享概念和必要父分类保留；共享概念的状态根据剩余证据重新计算。删除项目不会通过其他项目的旧撤销记录恢复已清除的概念。
