| R06 | 概念树节点用 `state.familiarity` 显示“已理解（自述）/已声明会/已学过/部分理解/需要帮助/已接触/未记录”，范围改为 `state.ranges` 的逐条“范围（维度：事实）”，不再依赖旧维度 `confirmed` 或 `manualStatus`。 |

| R09 | 普通首轮提问对问题/选中文本中明确出现的概念记录中性 `asked_question`（strength 0、reliability 0.8），不把回答提及算作用户接触，也不推断不会。 |
| R10 | 提问事实绑定 `projectId/qaRecordId/sourceType/sourcePath`；删除回答时按 `qaRecordId` 撤销其全部事实并清理该回答路径的来源证据，其他回答对同一概念的接触保持有效（历史行无 projectId 时按 qa_record_id 兼容）。 |
| R11 | `KnowledgeForest.requirements(projectId)` 读取有效 `user_teaching_requirements`（项目优先、全局随后、未激活忽略），`teachingContext` 将“当前明确要求”置前、已存原文要求随后合并且去重；桌面迁移来的要求参与 Android 生成。 |
