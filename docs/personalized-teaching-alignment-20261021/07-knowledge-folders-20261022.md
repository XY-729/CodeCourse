# 学习档案知识树与历史整理（2026-10-22）

## 用户可见变化

- 删除重复的“知识边界”视图，将“概念状态”统一为默认打开的“知识树”。判断依据、模型调用与术语提示仍有独立入口。
- 知识树按数据库中的父子关系展示成可折叠文件夹，初始收起大类；支持逐层展开、展开全部、收起全部以及搜索。
- 搜索命中概念时保留并展开它的祖先路径。例如 C++ → 标准库 → 容器与迭代器 → std::vector。
- 叶概念继续显示事实状态、已记录的知识范围，以及“依据”和人工纠正入口。新增的分类节点仅组织知识，不代表已讲过或已理解。
- 尚未归类或父关系异常的概念进入“待归类”，不会被随意当成新的知识领域；乱码标记、控制字符与已隔离条目不进入展示树。

## 数据与接口

桌面概念列表原先丢失 parent_id，现改为按权威树的可见范围返回父节点、归类状态和作用域。Android 同步返回归类状态并过滤已隔离记录，避免再次表现为平铺列表。

历史整理先使用已配置模型进行语义分类，再进行逐项复核、名称纠正和无学习事实的重复候选整理。模型只提出名称与分类，不设置熟悉度。确定的分类方案由本地事务服务应用，检查身份、父关系、作用域、无环性以及操作幂等性。

本机原有 1,632 个概念记录，整理结果：

| 项目 | 数量 |
| --- | ---: |
| 保留并归类的历史条目 | 859 |
| 修复名称 | 184 |
| 隔离无效或重复候选 | 773 |
| 其中无学习事件/教学引用的同名重复候选 | 62 |
| 新增分类节点 | 97 |

隔离通过 archived 标记实现，保留原 ID、原始行、正文引用与学习事实；每项原始身份、父关系及分类决定均存入知识树审计记录。完整 SQLite 备份位于本机 CodeCourse 数据目录的 backups 下，整理任务号为 history-folders-20261022-v1。

应用前后逐表内容哈希一致：27 条问答、7 条学习事件、23 条学习证据、55 个教学文档记录、224 条教学引用、3 条理解反馈及原有人工掌握记录。没有删除这些来源或更改其内容。分类节点均保持“暂无学习记录”。

已隔离身份不会阻塞后续有效清单重新登记同名概念；桌面导入、重启同步与 Android 身份分配均保留此行为。
