# QA 与课件共用知识树输入（2026-10-25）

QA 普通回答、术语解释、替代讲解和流式追问都通过 `prepare_question`，统一复用课件的 `build_lesson_context`：上传总纲大概念下的当前子森林、连接祖先和已讲范围清单。不再用问题中的关键词裁剪知识树。

用户明确选择的无总纲行为：继续正常回答，不上传知识树。总纲缺少有效清单、已删除或锚点失效时也采用该规则。请求保留当前问题、用户明确要求、语言设置及已授权的问答材料；不发送空树冒充完整学习记录，也不根据缺少记录推断用户没学过。

## 总纲选择

1. 优先使用课件或已有回答保存的总纲绑定。
2. 未保存绑定的旧课件通过知识图谱的 `parent_of` 关系定位原总纲；旧追问沿父回答和来源回答追溯。
3. 直接从总纲提问时使用该总纲；子总纲及重命名总纲分别保留自己的森林。
4. 没有明确来源时使用项目主总纲；主总纲不存在且仅有一个可用总纲时可选用该总纲。有明确归属但总纲被删时，不切换到其他总纲。

QA 冻结本次范围，入库时把范围保存到既有 `lesson_scope_json`，使用同一父节点、归属和总纲版本校验。若清单试图创建森林外的根节点，正文仍可阅读，对应知识清单标为无效，不写入孤立根。
