# 个性化教学原理核对与并行改造计划

审查日期：2026-10-21。代码基线：0f08b71022d6544a96884e14d0a937980837667e。

本轮只审查并写文档，没有修改应用代码、数据库、提示词或本机安装。以下接口、状态名与表结构均为改造建议，不是已存在的实现。结论来自源码和现有测试的静态阅读，本轮没有重新运行应用测试。

## 结论

**目前部分原理一致，但还不是你要求的完整流程。** 概念身份、教学覆盖清单、理解反馈、学习证据、章节分工和术语提问入口可以复用。主要缺口是：没有统一的概念父子树；不同生成入口的知识清单产生时间不一致；上下文按相关性截取；完成课件仍可能用 AI 补索引；术语有数量和密度限制；固定偏好、诊断功能、关闭开关仍参与流程。

目标流程：

> 创建计划识别根 → 总纲、课件、问答使用同一知识树与用户要求 → 内容和知识清单同次生成 → 软件校验保存 → 用户确认理解时直接用清单更新证据与树 → 后续生成使用更新结果。

课件在此基础上增加“统一章节分工 → 并发生成 → 最终拼接时按最新树标注术语”。三类内容只有生成格式、材料和任务要求不同。

## 逐项异同

| 你的要求 | 当前情况 | 应如何改 |
| --- | --- | --- |
| 总纲、课件、问答都纳入同一个性化机制 | 课程侧已有教学上下文；QA 主路径只读取精简摘要，旧完整构建函数和即时规划函数没有实际调用 | 建立公共上下文服务，所有实际入口接入 |
| 新建 C++ 计划就产生 cpp 根，STL、vector 按父子关系挂接 | 创建计划只建立项目记录和目录；现有知识网络主要连接文档、问答、来源，概念关系另有一套图 | 复用概念身份，建立权威父子森林及计划根关联 |
| 熟悉度有可核对依据 | 有事件、教学片段、人工反馈和 V2 证据，也有概率先验与观察器推断 | 保留可追溯事实，不能把先验分数当实际熟悉度 |
| 生成内容时返回知识清单和父节点 | 课件已有 TEACHING 清单，包含范围和原文，没有父节点；实际 QA 快路径禁止同次清单，后台元数据也不补 TEACHING | 扩展现有清单，统一同次返回并保存 |
| 标记理解立即在后台更新，不用 AI | 片段理解反馈已经是本地更新；课程完成遇到索引缺失会调用 AI 补录；旧 QA 总结另走概念匹配 | 统一为已存清单驱动，确认操作零模型调用 |
| 每次生成传完整树并尽量缓存 | 目前只选相关概念、最近摘要、部分已学范围，有数量和字符上限 | 全量精简树快照，稳定前缀和真实用量统计 |
| 避免旧知识重复，也让并发章节知道各自职责 | 已有共享全部章节及 focus 的真实并发协调，不是从零开始 | 补概念＋范围的稳定归属、全量树和最终覆盖校验 |
| 拼接后查最新树，所有陌生术语有入口 | 当前合并模型挑出的有限 TERMS，存库和展示还会截断；缺少最终最新树闭环 | 完整候选池＋最终本地重判，去掉数量与密度配额 |
| 点击术语生成解析走提问路径 | 已实现，含来源、选区、术语与历史解释关联 | 继续复用普通 QA，简化自动问题，不加固定教学顺序 |
| 删除诊断题等不符合要求的画像功能 | 诊断题并非全是空壳：题目存储、评分、撤销和证据链存在，Android 还有候选落库 | 按你的要求整条退出新个性化流程，不能只删按钮 |
| 删除术语密度、深度、原理优先等设置 | UI、偏好存储、自动推断、上下文指令和显示配额都存在 | 一起清理，保留用户原文要求 |
| 删除个性化/用户分析开关，强制开启 | 两个开关真实控制流程，未保存时默认关闭 | 移除关闭分支，旧 false 值不再生效，统一教学与证据分析常开 |

## 实现时要避免的歧义

1. 仅存概念名和单个熟悉度不足以防重复。“讲过 vector”可能只讲声明，未讲扩容。树节点保持简洁，但需要保存实际讲解范围摘要，详细证据单独存。
2. 列入总纲、生成讲解、用户问过、用户学完、用户理解是不同事实。普通提问只证明接触；总纲的未来目标不等于讲过。总纲里确实解释的内容，应与课件、回答一样记录。
3. 全量树不保证 token 少或缓存命中，需要实际测量。稳定序列化可以帮助复用前缀，状态变化仍会影响缓存。
4. “所有陌生术语”应对最终正文里的技术术语完整提供候选，再逐项比对树。不能用“最多 12 个”保证全部；也不能把“没有记录”写成“已确认不会”。
5. 父子关系表达归属，不能传播掌握度。理解 vector 不代表理解整个 STL，更不代表会多线程。
6. “用户分析强制开启”应落实为持续处理有依据的清单、行为与反馈，不能仅把旧观察器开关改 true，继续写无依据的偏好和能力猜测。
7. 自动补父是必做流程：先复用已有合理父，小概念缺父时同次生成补必要父/祖先链，再挂到已有合理祖先或新领域根。结构祖先不代表已讲过或已理解；确认理解阶段不再调 AI。具体规则见共同契约 2.1。
