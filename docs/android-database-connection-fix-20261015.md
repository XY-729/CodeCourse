# Android 数据库连接恢复修复（2026-10-15）

## 问题

手机显示 `CreateConnection: Connection codecourse_mobile already exists`，项目列表及项目内容无法打开。原实现仅缓存成功初始化的 JavaScript 实例；初始化在打开连接后失败，或 WebView 重新加载而原生连接仍存在时，下次初始化会重复创建同名连接，覆盖最初的错误并阻止重试。

## 修复

- 根据原生 `isDBOpen` 状态复用已打开连接，打开已登记但关闭的连接，仅在明确没有连接时创建。
- 处理探测与创建之间出现的同名连接；仅接受该具体冲突，其他原生错误继续上报。
- 数据库实例共享初始化和写事务队列，防止重复迁移及跨实例并发事务。
- 初始化失败后允许重新执行；保留原数据库文件、加密密钥和业务数据。
- 升级后读取实际全文索引类型，防止把已存在的 FTS4 索引误认为 FTS5。

- 前端 114 个文件、632 项测试通过。

- 使用 v0.4.2 的真实历史表结构在独立 SQLite 中升级；项目、课件登记、问答、阅读进度及设置保留，FTS4 类型正确，重新创建 JavaScript 实例后仍可读取。
