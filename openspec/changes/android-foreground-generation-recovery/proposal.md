# Android 前台生成与检查点恢复

## 背景

Android WebView 在应用进入后台后可能被暂停或终止。原生前台 Service、WakeLock 和渲染优先级不能保证其中的 TypeScript 生成逻辑继续执行，持续显示“后台生成”会误导用户。

## 决策

- Android 生成只承诺在应用前台运行。
- 生成进度和中间结果持久化到 SQLite；重新打开应用后从有效检查点恢复。
- 原生通知只报告生成完成，不模拟后台进度。
- 不申请前台服务、WakeLock 或电池优化豁免权限。
- Android Web 构建使用独立入口，排除无法迁移的桌面窗口、Monaco、桌面工具栏和桌面手势代码。
