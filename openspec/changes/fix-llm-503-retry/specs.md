# Spec: fix-llm-503-retry

## REQ-1: 后端 LLM 调用对瞬态错误指数退避重试

`call_openai_compatible_chat_result` 与 `stream_openai_compatible_chat` 必须对瞬态错误自动重试（最多 3 次尝试），不可恢复错误（4xx）不重试。

### 验收标准

- **AC-1.1** 同步调用对 408/429/500/502/503/504 重试；连续 2 次失败 + 第 3 次成功时返回成功结果。
- **AC-1.2** 同步调用对 401/403/400/404 等 4xx 立即抛 `RuntimeError`，不重试。
- **AC-1.3** 网络错误（`httpx.HTTPError`）重试。
- **AC-1.4** 流式调用对 503 同样重试；`[DONE]` 之前的 SSE 解析逻辑不变。
- **AC-1.5** 3 次全部失败时抛最后错误；重试间隔指数退避（1.5s / 3s）。
- **AC-1.6** 成功响应、空 content、非 JSON 等现有行为不变。

## REQ-2: 安卓 LLM 调用区分错误类型重试

`localProvider.ts` `callLLM` 对瞬态错误指数退避重试（最多 3 次），不可恢复错误直接抛。

### 验收标准

- **AC-2.1** 429/5xx/网络异常重试，退避 3s / 6s。
- **AC-2.2** 401/403/400/404 立即抛错，不重试。
- **AC-2.3** "模型返回了空内容"、"请先配置模型"不重试（现有行为保留）。
- **AC-2.4** 3 次失败抛最后错误。
