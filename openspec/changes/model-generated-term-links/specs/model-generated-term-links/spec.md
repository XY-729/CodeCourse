# 术语链接词改为生成时由模型选择

## Spec

### Requirement: 链接词在生成时由模型产出

- **When** 总纲/子总纲/学习计划课/文件课件/QA 回答生成时
- **Then** 模型结合注入的学习画像输出单行 `TERMS: [...]`,每节课件 0-3 个、回答最多 12 个,允许空选择;正文与术语同一次生成确定,元数据行不进入正文与流式输出

### Requirement: 读取/生成不再启发式挖掘与补扫

- **When** 打开已有课件或生成内容落库时
- **Then** 不运行正则/词典/标识符/代码索引候选挖掘,不因候选不足触发额外模型补扫;生成产出的术语整批替换旧 model 术语(manual 行保留),空选择也生效

### Requirement: 只把可信术语变成链接

- **When** 正文渲染匹配术语
- **Then** 代码块内、已有链接、标题与加粗强调句、句中碎片、临时变量、示例输出不产生链接;正文普通词可标;行内代码术语仅整 span 匹配时装饰且保持代码样式;标识符类术语要求整词边界

### Requirement: 学情覆盖模型选择

- **When** 某术语的学习档案为手动 known 或 knowledge_status=confirmed
- **Then** 该术语不显示为链接;手动 unknown 突出显示;其余 model 选择仅受阅读密度与重复限制,默认 subtle

### Requirement: 手动链接不被自动机制覆盖

- **When** 用户手动创建过术语链接或对旧术语行进行过手动操作
- **Then** 自动替换/过期清理不删除、不改变该行;手动链接不占用自动展示预算

### Requirement: 扫描状态与重扫入口统一

- **When** 阅读课件/回答或打开学习档案弹窗
- **Then** 术语标注状态以统一控件展示(完成/进行中/失败/缺模型授权),重扫需用户确认并仅当模型已授权时可用;轮询仅在 queued/running 进行;术语缓存按项目隔离

### Requirement: 界面不闪现旧决策

- **When** 切换文档或术语档案加载期间
- **Then** 不先按旧档案渲染一批链接再刷新(加载/中止期间不产出展示决策)

## Test Plan

1. 生成 C++ 课件 → 术语落在模型选择集合内;正文无 TERMS 行;示例代码/标题/链接不产生术语链接
2. 打开既有文档 → 不触发补扫请求;model 扫描记录为 completed
3. 课件回归页:仅 `std::vector` 成链,强调句("禁止编译器偷偷做类型转换")与碎片("它只是把")不成链;confirmed 术语抑制后 inline code 仍可读
4. 手动标 known/unknown/建链接 → 展示与保留符合覆盖规则
5. 工具栏/档案弹窗重扫:未授权禁用、失败可重试、busy 防抖
6. 后端 322 项 + 前端个人化相关套件通过;生产构建通过
