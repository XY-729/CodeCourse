# QA 手动追问与稳定主题归类

## Spec

### Requirement: 普通提问默认独立会话(移动端)

- **When** 一次问答完成后,用户直接在输入区提出新问题(未点击"追问")
- **Then** 新问题开启全新会话,不携带上一问答链上下文;回答完成后同样回到"下一次提问独立"状态

### Requirement: 历史记录可手动追问

- **When** 用户在历史记录操作栏点击某条回答的"追问"按钮
- **Then** 进入追问状态:后续提问携带该回答链的上下文(parent 关联),界面显示"正在追问:<主题>"状态 chip

### Requirement: 追问可主动取消

- **When** 追问状态中,用户点击 chip 旁的取消
- **Then** 追问记录清除,回到默认独立会话,输入区恢复普通提示

### Requirement: 输入框占位文字统一

- **When** 打开问答输入区
- **Then** 占位文字统一为"请输入问题"

### Requirement: 跨项目回答不可追问

- **When** 查看的是其他项目中的历史回答并点击"追问"
- **Then** 不进入追问,提示"其他项目的回答只能查看,不能追问"

### Requirement: 稳定主题归类

- **When** 模型对用户问题生成"继续学习"主题,或旧历史主题被简化合并
- **Then** 主题为简短稳定的上位知识分类(如"并发与内存模型"、"C++ 新特性"),不复制用户问题/TITLE/表达式/函数名;同一分类的问答记录合并为一个续学条目;新问题优先复用上下文注入的 `<existing_qa_topics>` 中已有分类

### Requirement: 桌面端行为不回归

- **When** 桌面端(非移动布局)完成一次问答后再次提问
- **Then** 行为与推送前一致(沿用既有会话编排),不因会话编排重构而回归

## Test Plan

1. Android:连续提问两问 → 第二问为独立会话(不引用第一问链)
2. Android:点击历史"追问" → 显示"正在追问",提问续接该链;取消后下一问回到独立会话
3. Android:提问 shared_ptr 后查看"继续学习"卡片 → 归入"C++ 新特性";再问 unique_ptr → 复用同一分类且两条合并
4. Android:历史中大量长文本旧主题 → 自动简化并合并展示
5. 桌面:提问 → 追问 → 行为与 origin 相同(vitest 移动/桌面布局用例覆盖)
