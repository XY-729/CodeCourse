# QA 手动追问与稳定主题归类

## Why

用户反馈(问答栏使用体验):

1. **提问串链不可控**:普通提问完成后,下一次提问被自动续接到上一问答链,新问题与旧上下文混杂,模型回答受无关历史影响。用户希望"默认独立会话,只有主动点击才续接追问"。
2. **追问链路不可见**:历史回答链只能整链延续,无法看到"当前正处于对哪条的追问中",也无法中途取消。
3. **主题归类不稳定**:`shared_ptr`、`unique_ptr`、`weak_ptr` 等同类问题每次被归类成不同主题(直接抄写问题文本/表达式),历史"继续学习"卡片碎成多条近似主题,无法合并复用。

## What Changes

1. **默认独立会话**:普通提问回答完成后,下一次提问开启全新会话;仅当用户在历史记录操作栏点击"追问"按钮,才携带对应问答链续接。
2. **追问可见可取消**:追问进行中显示"正在追问:<原问题摘要>"状态 chip,可主动取消回到独立会话;输入框占位文字统一为"请输入问题"。
3. **稳定主题归类**:模型收到的上下文包含现有主题列表,优先复用简短稳定的上位知识分类(如"并发与内存模型"、"C++ 新特性"),不得复制用户问题/TITLE/表达式/函数名;旧历史数据自动简化主题,相同分类自动合并展示。
4. **双端同步**:Android 端(移动布局)完整获得上述交互;桌面端行为边界见 design.md(追问 UI 与 persona 改动交织,留在本地工作树,推送树中桌面端保持原语义不回归)。

## 非目标

- 不改动问答检索/生成管线本身(仅会话编排与上下文注入)
- 不在此次推送中包含桌面 ExplainPanel 的追问 UI(persona 风格改动的一部分,另行推送)
